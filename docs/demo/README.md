# AgentPay walkthrough recording

This is the recording script for the Level 5 submission. Keep the final video to 2–4 minutes and show the browser, wallet confirmation, and the resulting Stellar testnet transaction.

## Walkthrough

1. Open the live app: <https://agentpay-seven.vercel.app>.
2. Start on **Home** and explain the one-sentence value proposition.
3. Connect a Stellar testnet wallet and show the calm, plain-language status label.
4. Open **Find an agent**, select a service, and show the provider, price, and payment path.
5. Approve a request and show the wallet confirmation.
6. Open **Activity** and point to the transaction status.
7. Open the contract in Stellar Expert using the contract address in the README.
8. Close with the test cohort ask: 5 minutes, one testnet wallet interaction, and honest feedback.

## Capture checklist

- Use a fresh browser window with no private keys or seed phrases visible.
- Use testnet funds only.
- Record one desktop flow and one mobile-responsive view.
- Keep the final public URL in the README once uploaded to Loom or YouTube.
